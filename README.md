# 云卜轩 · 国风占卜游戏

一殿十一术：东西方占卜玩法合集，暗金国风 + 星空粒子的炫酷 2D 网页。

## 玩法

| 分组 | 玩法 | 亮点 |
|---|---|---|
| 镇殿五术 | 小六壬 | 六宫环形报数动画（月上起日、日上起时），农历/公历、此刻/指定时间 |
| | 塔罗牌 | 洗牌 → 扇形牌阵自选 → 3D 翻牌；单张 / 过去·现在·未来三张牌阵，44 套原创判词 |
| | 观音灵签 | 按住蓄力摇签筒（签支碰撞音效），松手落签抛物线飞出；60 签原创签诗 + 所问之事提示 |
| | 六爻 | 3D 铜钱翻滚掷卦，卦架逐爻点亮；纳甲、六亲、世应、六神、旬空、月建简断，本卦/变卦 |

统一约定：吉 = 暖金、凶 = 靛蓝；结果页均标注「仅供娱乐」；每种玩法首次完成点亮一枚印章（印章簿），历史记录见「占卜录」，数据仅存本机 localStorage。随机数取自 `crypto.getRandomValues`。

## 开发

```bash
npm install
npm run dev       # 本地开发
npm test          # 算法与文案单元测试
npm run build     # 类型检查 + 产出 dist/（相对路径，可直接部署到任意静态托管）
npm run build:single  # 产出 dist-single/index.html，JS/CSS 全部内联的单文件版本
```

技术栈：Vite + React 19 + TypeScript；历法、节气、八字、黄历使用 [lunar-javascript](https://github.com/6tail/lunar-javascript)。音效由 WebAudio 实时合成，无音频资源。

## 目录

- `src/games/` 各玩法页面与样式，`meta.ts` 为玩法注册表
- `src/data/` 签诗、判词、批语等原创文案与查表数据
- `src/lib/` 算法：六十四卦/京房八宫/纳甲（`hexagram.ts`）、八字分析（`bazi.ts`）、历法工具、存储、音效
- `src/components/` 星空背景、罗盘、签筒、结果卡、印章等通用组件
